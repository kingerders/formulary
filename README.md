# Formulary

**Formulary** is an iOS formula reference app for engineering and science disciplines.

- 16 disciplines: Mathematics, Physics, Chemistry, Civil Engineering, Mechanical Engineering, and more
- 3,000+ formulas with LaTeX rendering
- Variables, definitions, and interactive visualizations
- Offline access
- Available on the App Store
